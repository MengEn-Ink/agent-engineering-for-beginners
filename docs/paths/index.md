# 选择你的阅读路线

不用从第一页硬读到最后一页。选择最接近当前目标的路线，系统会在章节末尾推荐下一站；你也可以标记已读和加入书签。所有记录只保存在当前浏览器，清除网站数据后会消失。

<ReadingPaths />

## 怎么选择

- 第一次系统学习 Agent，选“小白入门”；
- 正在设计或实现 Agent 系统，选“工程实战”；
- 近期准备面试或方案答辩，选“面试冲刺”。

路线只是导航，不是等级。遇到项目里的真实问题，可以随时跳到对应章节，再回到路径页继续。
