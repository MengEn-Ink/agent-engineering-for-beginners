## 1. 本章或方案先回答什么

- 读者或用户：
- 完成后能做出的决策：
- 明确非目标：

## 2. 概念地图

- 关键组件：
- 组件关系：
- 谁拥有状态：
- 哪些是硬规则，哪些允许模型判断：

## 3. 工程拆解

- 输入与来源：
- 工具与权限：

## 4. 设计步骤

把步骤写成可执行动作。每一步说明输入、输出、完成条件和失败去向。

## 5. 案例与失败边界

- 适合做什么：
- 不适合做什么：

- 最终证据：

## 6. 可复制资产

提供决策表、schema、检查表或 runbook，而不是只给原则。

## 7. 练习与来源

- 练习任务：

## 发布前自查

- [ ] 关键事实有来源
- [ ] 当前能力与未来规划分开
- [ ] 没有内部地址、凭证和未授权数据
- [ ] 例子没有把偶然阈值写成行业定律
- [ ] 图表确实帮助解释
- [ ] 手机端可阅读
- [ ] 失败路径与人工接管完整
